# baybayin_learning_app

Baybayin learning app is an AI-driven web and mobile application that promotes holistic Baybayin education through interactive gamified learning with progressive learning journeys. It adapts to a learner’s pace and performance, reinforcing mastery through layered activities and personalized challenges.

Alongside this, the system features a transliteration pipeline that bridges Baybayin and modern Latin-based Tagalog. It supports input via typing (with a virtual Baybayin keyboard), image upload, and live camera capture—processing through a pipeline of OCR, binarization, and translation to ensure accurate script recognition and linguistic fidelity.
